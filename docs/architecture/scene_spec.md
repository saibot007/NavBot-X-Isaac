# Aegis Inspection Bay — Scene Specification

## Scene Identity
Aegis Inspection Bay is a futuristic industrial inspection facility built to showcase a premium autonomous rover operating in a clean, high-tech environment.

## Scene Purpose
The scene should immediately communicate:
- advanced robotics
- industrial intelligence
- premium engineering
- clean simulation aesthetics
- future-readiness for autonomy and Physical AI workflows

## Phase 1 Scene Layout
The first version of the scene should include:

1. **Deployment Zone**
   - rover spawn/start area
   - visually clean
   - marked as mission starting point

2. **Main Inspection Lane**
   - central driveable lane
   - wide enough for smooth vehicle movement
   - visually readable from top and side camera angles

3. **Inspection Points**
   - 3 checkpoints:
     - Checkpoint A
     - Checkpoint B
     - Checkpoint C
   - placed along the mission route
   - visually distinct from the floor

4. **Industrial Props**
   - clean box-like machinery or inspection units
   - side structures or wall modules
   - a few obstacles for visual richness

5. **Boundary Definition**
   - side walls, pillars, or railings
   - enough to frame the rover and improve scene composition

## Visual Style
Use the following style language:

- dark grey / metallic floor
- cool blue or cyan accent lighting
- silver / steel structural elements
- warning-strip or lane-marked navigation paths
- premium industrial sci-fi appearance
- uncluttered composition

## Camera-Friendly Design
The scene should look strong from:
- one front three-quarter hero angle
- one top-down route angle
- one side tracking angle

## First Demo Goal
The rover should:
1. appear in the Deployment Zone
2. move through the Main Inspection Lane
3. visit Checkpoint A, Checkpoint B, and Checkpoint C
4. finish in a visually strong end-frame

## Design Constraint
Even if the backend remains simple in Phase 1, the visible environment must feel premium and intentional.

## Future Expansion Path
The scene should later support:
- autonomous navigation policies
- Isaac Lab task integration
- camera-based gesture override
- richer physics
- more advanced assets and lighting
