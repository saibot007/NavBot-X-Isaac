# Inspection Route Alpha

## Mission Purpose
Inspection Route Alpha is the first showcase mission for NavBot-X Rover inside Aegis Inspection Bay.

## Route Flow
1. Start at Deployment Zone
2. Move toward Checkpoint A
3. Continue to Checkpoint B
4. Continue to Checkpoint C
5. End on a final hero position

## Demo Purpose
This route is designed for:
- first scripted motion demo
- early scene composition testing
- camera angle testing
- future transition into autonomous and RL-driven tasks

## Visual Goal
The route should be simple enough to execute cleanly, but visually strong enough to feel intentional and premium in a short showcase video.
