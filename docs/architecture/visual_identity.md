# NavBot-X Isaac Lab — Visual Identity

## Project Visual Goal
The project should look like a flagship robotics simulation project at first glance.

The visible identity should communicate:
- futuristic robotics
- premium engineering
- intelligent autonomy
- industrial realism
- high-end simulation direction

## Project Naming Stack
- **Project:** NavBot-X Isaac Lab
- **Scene:** Aegis Inspection Bay
- **Vehicle:** NavBot-X Rover
- **Mission:** Inspection Route Alpha

## Rover Identity
NavBot-X Rover should look like a compact, premium inspection vehicle.

### Rover traits
- low-profile
- stable
- compact
- technical
- futuristic
- not toy-like

### Rover color language
- dark grey / black base
- blue accent elements
- silver or metallic highlights

### Future visual additions
- front sensor pod
- camera module
- light strip
- small mast or sensor head

## Scene Color Palette
Use a controlled, premium palette:

- **Primary:** dark grey / graphite
- **Secondary:** steel / silver
- **Accent:** cyan / electric blue
- **Marking colors:** white / yellow safety markings

## Lighting Direction
The scene should feel:
- cool-toned
- crisp
- high-tech
- readable on camera

Avoid:
- overly warm lighting
- overly cluttered scenes
- random bright colors
- game-like cartoon styling

## Demo Aesthetic
The first demo should feel:
- intentional
- smooth
- premium
- cinematic
- portfolio-ready

## Presentation Rule
If a visible choice does not make the project feel more premium, futuristic, or technically impressive, it should not be included.
